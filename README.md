🍽️ Varsha's Kitchen — Restaurant Billing & POS System

📌 1. Project Overview

Varsha's Kitchen is a multi-tier restaurant billing, Point of Sale (POS), and digital invoicing application developed using Python. It provides three integrated interfaces connected to a central SQLite database for efficient order processing, billing, receipt generation, and restaurant management.

Key Interfaces

- 🌐 Web POS & Digital Receipts ("app.py"): A Flask-based web application accessible at "http://localhost:8000" for placing orders, calculating bills, and generating print-ready receipts with embedded UPI QR codes.
- 🖥️ Desktop Management GUI ("restaurantmanage.py"): A Tkinter desktop application for viewing historical orders, managing table totals, and recording customer feedback.
- 💻 Interactive Terminal Billing ("RestaurantBillingSystem.py"): A command-line billing interface designed for quick counter billing, receipt printing, and simulated SMS dispatch.

🗄️ 6. Database Schema

The SQLite database, "Restaurant.db", contains the following tables:

Restaurantrecords

Stores billing information, including:

- Order number
- Food item quantities
- Meal cost and subtotal
- Tax and service charge
- Grand total

CustomerOrders

Stores transaction information, including:

- Customer mobile number
- Order timestamp
- Ordered item summary
- QR code filename

FEEDBACK

Stores customer feedback, contact information, and satisfaction ratings.

🚀 7. Installation and Setup

Prerequisites

- Python 3.x
- pip package manager

Step 1: Clone the Repository

git clone https://github.com/VarshaSP04/RestaurantBillingManagementSystem.git

Step 2: Navigate to the Project Directory

cd RestaurantBillingManagementSystem

Step 3: Install Dependencies

Install the packages required by your application:

pip install flask qrcode pillow

Install any additional dependencies imported by your Python files.

Step 4: Run the Application

Web POS & Digital Receipts

python app.py

Open "http://localhost:8000" in your browser if it does not open automatically.

Desktop Management GUI

python restaurantmanage.py

Command-Line Billing System

python RestaurantBillingSystem.py

🔄 8. Application Workflow

1. The user opens one of the three application interfaces.
2. Food items and quantities are selected or entered.
3. The application calculates the bill, including applicable taxes and service charges.
4. The order and billing information are stored in the SQLite database.
5. A receipt is generated, with QR code functionality where supported.
6. Order history and customer feedback can be accessed through the management interface.
